## 人工异常验收

- [ ] 拒绝连接或签名 → 显示失败，可重试
- [ ] 错误链 → 禁止交易并提示切换
- [ ] 新账户 → 不显示旧身份或旧权限
- [ ] RPC 失败 → 权限清空，不把未知余额显示成零
- [ ] 重复点击 → 一次交易
- [ ] 回执 reverted → 不解锁
- [ ] 交易广播后超时 → 保留 hash，可去浏览器核验
- [ ] 手机视口 / 键盘 Tab / 直达模块链接
